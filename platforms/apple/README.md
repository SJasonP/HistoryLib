# HistoryLib for Apple

English | [简体中文](README.zh-CN.md)

The native HistoryLib app for iPhone, iPad, and Mac, built with SwiftUI,
SwiftData, and CloudKit.

> HistoryLib is a vibe coding project; AI has done most of the work. If that
> concerns you, please do not use it. Please open an Issue first rather than
> submitting a pull request directly.

Import Safari, Google Takeout, and HistoryLib archives; browse and search
history; explore activity summaries; sync through iCloud; and export records
with optional password protection for native archives. Advanced search, record
actions, storage diagnostics, and voluntary tips are available in v1.4.

The minimum supported systems are iOS/iPadOS 26 and macOS 26.

## Source and documentation

- `HistoryLib/`: app code, assets, and localized resources.
- `HistoryLibTests/`: automated data-path and behavior tests.
- `HistoryLibUITests/`: UI regression tests.
- `HistoryLib.xcodeproj`: Xcode project.
- [`Documentation.docc`](Documentation.docc/Documentation.md): Apple documentation.

Start with the [client guide](Documentation.docc/Apple-Client.md) or the
[development guide](Documentation.docc/Development.md) to build from source.
Shared formats and product contracts are in [`shared/specs`](../../shared/specs/README.md).
